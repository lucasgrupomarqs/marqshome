# 🏡 Marqs Home - Institucional & Catálogo B2B

Website institucional de alta performance desenvolvido para a **Marqs Home**, uma importadora especialista em soluções para Casa, Jardim, Lazer e Linha Infantil. O projeto foi projetado com foco em **vendas corporativas (B2B)**, **SEO avançado** e **design premium responsivo**.

---

## ✨ Funcionalidades

- **Hero Section com Vídeo de Fundo:** Integração com YouTube (`iframe`) rodando em loop, com *autoplay*, modo silencioso e overlay translúcido para contraste perfeito com o texto.
- **Catálogo de Produtos com Efeito Hover:** Cards de categoria usando imagens reais em alta resolução de fundo. O conteúdo descritivo revela-se de forma suave ao passar o mouse (*hover reveal*).
- **Integração B2B via WhatsApp:** Formulário de captação de leads corporativos que redireciona automaticamente para o WhatsApp da equipe de vendas com uma mensagem pré-formatada.
- **Seção de Lojas Oficiais (Varejo):** Cards minimalistas e premium direcionando para os canais de venda nos marketplaces (Mercado Livre, Shopee e Amazon).
- **Design Responsivo & Mobile-First:** Navegação adaptada para todos os dispositivos, incluindo menu *hambúrguer* otimizado e tratamento de *hover* em dispositivos móveis.
- **Animações Fluidas:** Utilização da biblioteca AOS (Animate On Scroll) para entrada suave dos elementos na tela.
- **SEO Avançado:** Implementação de Meta Tags completas, Open Graph (para redes sociais e WhatsApp) e estruturação JSON-LD (Schema.org) para o Google.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído sem frameworks pesados, garantindo velocidade extrema e facilidade de manutenção:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Variáveis nativas, Flexbox, CSS Grid, efeitos de transição/transformação e *Glassmorphism* (efeito de vidro).
- **Vanilla JavaScript:** Lógica do menu mobile e envio de formulário para WhatsApp.
- **AOS.js:** Biblioteca leve para animações de rolagem.
- **FontAwesome 6:** Ícones vetoriais em alta qualidade.
- **Google Fonts:** Tipografia moderna '*Inter*'.
